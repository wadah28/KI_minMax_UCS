

## Einrichtung

1. Abhängigkeiten installieren:
   ```
   pip install termcolor
   ```

2. Ausführen

   ```
   python controller.py
   ```
   
> **Hinweis:**  
> Wenn Sie mit PyCharm arbeiten, müssen Sie ggf. das Anzeigen von Farben in der Konsole aktivieren. Gehen Sie zu Run > Edit Configurations, wählen Sie Ihre Python-Konfiguration aus und aktivieren Sie unter "Modify Options" die Option "Emulate terminal in output console".
