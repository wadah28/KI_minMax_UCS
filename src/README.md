# KI-Spielentwicklung - SoSe 26

Quellcode zum Praktikum. 


## Ziel des Spiels

Das Spiel wird auf einem 3x3-Gitter gespielt. 
Zwei Spieler setzen abwechselnd Kanten zwischen benachbarten Punkten. 
Wenn eine Box gebildet wird, darf der Spieler sie mit seinem Symbol markieren. 
Ziel ist es, am Ende die meisten Boxen zu besitzen.

## Aufgaben

### Quellcode-Analyse

Analysieren Sie den vorhandenen Quellcode. Kommentieren Sie die Funktionen und Klassen, um deren Zweck klar zu kommunizieren. Das Verständnis der Struktur ist entscheidend für die Implementierung der fehlenden Spiellogik.

### Implementierung

Fügen Sie die fehlende Spiellogik hinzu, um den vollständigen Spielverlauf gemäß des Aufgabenblattes ermöglichen. Dies beinhaltet das Abschließen von Boxen und deren Bewertung für einen potenziellen Gewinn des Spiels.
